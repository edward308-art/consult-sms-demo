# 상담 요약 SMS (Vercel 배포용 데모)

서버에 아무것도 저장하지 않는 버전입니다. 입력한 내용은 사용자의 브라우저에만 보관되고, 문자는 실제로 발송되지 않습니다(모의).
**가상 데이터만 입력하세요.**

## 폴더 구조
- `public/index.html` — 화면(직원 검토 UI)
- `api/index.py` — 서버 함수(모든 /api 요청 처리)
- `bank_lib/` — 마스킹·요약·추천·업무 로직
- `vercel.json` — Vercel 설정
- `dev_server.py` — (선택) 내 컴퓨터에서 미리보기: `python3 dev_server.py` → http://127.0.0.1:3000

## 필수 환경변수 (Vercel 프로젝트 Settings → Environment Variables)
| 이름 | 값 | 설명 |
|---|---|---|
| `APP_SECRET` | 16자 이상 임의 문자열 | **필수.** 상태 서명 키. 없으면 화면에 "설정 필요"가 뜹니다 |
| `DEMO_ACCESS_CODE` | 접속 코드(선택) | 설정하면 코드를 아는 사람만 입장 |
| `FOUR_EYES` | `1`(선택) | 상담원과 검토자가 다른 ID여야 승인 |
| `NIGHT_AD_CHECK` | `0`(선택) | 야간 광고 차단을 끔(시연용) |

## 동작 방식
승인 여부 같은 상태는 서명(HMAC)과 함께 브라우저가 들고 다니며, 서버가 요청마다 서명을 검증합니다.
따라서 브라우저에서 상태를 조작해도 "승인 전 발송 불가" 규칙은 우회되지 않습니다.
